# Preparing a photo for an 8 × 10 inch print

## Crop first, then count pixels

An 8 × 10 inch print has a 4:5 aspect ratio. For a 300 PPI print, aim for 2,400 × 3,000 pixels after cropping. A 3,000 × 4,000 portrait cropped to 4:5 can retain 3,000 × 3,750 pixels. It already clears the target.

## When the crop is too small

A 1,200 × 1,500 crop needs twice as many pixels along each edge to reach the same target. Open the [Whisk AI image upscaler](https://whisk-ai.io/image-upscaler), export a larger version, and check the actual dimensions. Inspect lettering, hair and fine texture at 100% before ordering a print.

## Other print sizes

Use the [print sizing table](https://docs.google.com/spreadsheets/d/e/2PACX-1vR5dST6LnJeSgOptk6UMd11TqdIV80wpd_rbINEIU2ajm21KD7dJwVEGcmsyz3kMrXEIYsXrlvrrnfx/pubhtml) for 4 × 6, 5 × 7, square and larger prints. If your print shop specifies a different PPI, multiply each print edge in inches by that number instead.
